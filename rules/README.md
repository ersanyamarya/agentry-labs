# Rules

User-level Claude Code rules. `scripts/setup.sh` installs every rule here (except this README) into `<config>/rules/`, so they apply in every project.

| Rule | Purpose |
|---|---|
| `commit-attribution.md` | No AI attribution lines in commits or pull requests |
| `context7.md` | When and how to fetch current library docs with the Context7 MCP |
| `trail.md` | Use the trail CLI before grep or reading whole files in indexed repos |
